CodexSync隐私政策使用风险

隐私政策

生效日期：2026-10-08。本政策适用于 CodexSync 的 Google Drive 集成及本地数据同步功能。

访问与用途

Google Drive 隐藏库使用 drive.appdata 权限；可见备份文件夹使用 drive.file 权限，仅操作本应用创建或经用户授权的文件。两种存储分别授权，旧隐藏库保留，不请求全盘访问权限。软件无需读取 Gmail、通讯录或日历。

用户选择的本地数据可能包含对话、配置、凭据、插件和 skills。这些数据仅用于用户请求的备份、同步和恢复，不用于广告、出售、分析画像或训练通用人工智能模型。

保存与加密

Google OAuth 令牌保存在本机状态目录，并使用用户的主密钥加密；令牌不会作为同步数据上传。全部加密模式在本机通过 XChaCha20-Poly1305 加密内容与清单。原样模式保留目录、文件名与未加密内容，并使用标准 JSON 快照信息；部分加密仅保护用户选中的内容，目录和文件名仍可见。请在上传前检查保存方式及范围。本机缓存与任务状态仍加密。主密钥由用户保管，开发者不能代为找回。请勿将主密钥或其他不应上传的文件放入所选同步目录。

本机配置、日志和加密缓存用于运行及故障排查，不会自动发送给维护者。Google 可按其政策处理必要的账号、网络请求、时间与容量等服务元数据；加密并不能隐藏所有元数据。

共享和第三方服务

软件不向开发者提供数据托管，不自动向维护者发送 Google 用户数据或本地备份。仅向用户选择的 Google Drive、WebDAV 或本地仓库写入备份。Google、WebDAV 提供方和用户自行选择的其他服务各自适用其隐私政策。

CodexSync 对通过 Google API 收到的信息的使用及传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销和删除

本机状态及远端备份保留至用户自行删除；软件不会自动传播源文件删除。用户可关闭自动同步，并通过 Google 账号的第三方连接页面撤销访问。撤销授权不等于删除已有备份。可通过 Google Drive 的“设置 → 管理应用”管理本应用的隐藏应用数据，或在网盘中管理可见备份文件夹；删除前应确认独立备份可恢复。本机数据及凭据由用户自行管理。

网站与联系

本说明网站由 GitHub Pages 托管，不嵌入广告、分析脚本或追踪 Cookie。GitHub 可能按其政策记录网站访问。隐私问题请通过 项目问题页联系维护者；不要在公开问题中提交密钥、令牌、私人对话或其他敏感数据。

政策变更

功能或数据处理方式发生变化时，本页面将更新生效日期。新的权限应另行征得用户授权。
