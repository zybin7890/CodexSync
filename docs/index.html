CodexSync

个人维护的开源 Codex 本地数据备份与同步工具，使用 C/C++ 和 Qt。提供 Windows 与 Debian 的桌面界面、终端模式和 API，支持本地仓库、WebDAV 和 Google Drive。

当前软件仍处于开发预览阶段。请先使用测试数据验证恢复，不要将其作为唯一备份；本页上线不代表发布了新软件版本。

Google Drive 如何使用

通过 Google 浏览器授权访问本应用专用数据空间，权限仅为 drive.appdata。软件将用户选择的数据加密后备份到该空间，不请求读取其他网盘文件。

Google 授权只建立连接，不会自动上传数据。上传由用户启动备份或在软件运行时启用自动同步触发。主密钥应独立保管，丢失后无法恢复数据。
